# nlp-whatsapp-chat-analyzer

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/BurhanxGodhra/nlp-whatsapp-chat-analyzer/blob/main/whatsapp_chat_analyzer.ipynb)

Natural language processing pipeline for messaging frequency and sentiment analytics.

## Overview
This repository contains a standalone Jupyter/Colab notebook setup for rapid execution and reproducibility.

## Quickstart
1. Click the **Open in Colab** badge above to launch directly in Google Colab.
2. To run locally:
   ```bash
   git clone https://github.com/BurhanxGodhra/nlp-whatsapp-chat-analyzer.git
   cd nlp-whatsapp-chat-analyzer
   pip install -r requirements.txt
   jupyter notebook whatsapp_chat_analyzer.ipynb
   ```
